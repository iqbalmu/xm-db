# DBM - Database Management CLI

A powerful CLI tool for managing development databases. Supports MySQL and PostgreSQL with easy Docker container management.

## Features

- 🚀 Quick database creation with interactive prompts
- 🐳 Automatic Docker container management
- 🔄 Easy start/stop/remove operations
- 📊 Table listing and structure inspection
- 🔗 Connection string generation
- 💾 Built-in backup and restore (coming soon)
- 🔀 Database cloning (coming soon)
